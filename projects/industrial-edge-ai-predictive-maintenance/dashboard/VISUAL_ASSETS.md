# EDGEOPS visual assets

Two original AI-generated concept images were created on 19 November 2026 using the built-in image generation tool and encoded locally as WebP for the application. No external image service, tracking request, or stock-image license is required.

- `edgeops-bench-concept.webp`: conceptual motor, sensor, ESP32 and edge-gateway bench composition. Used in the overview, sign-in, and motor asset detail preview.
- `edgeops-facility-concept.webp`: conceptual pump/motor utility hall. Used in the overview banner, sign-in atmosphere, and non-motor asset context preview.

These are illustrative compositions, not documentary photographs of the user's hardware, exact product selections, wiring instructions, approved safeguards, or evidence of an installed factory. Visible captions and alternative text preserve this distinction. Physical design remains governed by the reviewed hardware documentation and exact-part commissioning checks.

WebP encoding preserves the generated compositions without adding fake interface overlays or labels. Fixed image dimensions reduce layout shift; browser caching reuses the same two local assets across views. Existing SVG fallbacks remain available.
